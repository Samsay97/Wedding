# Аудит свадебного сайта

Проверен архив `Wedding.zip`: HTML, CSS, JavaScript, структура папок, ссылки на ресурсы и история Git.

## Почему сайт был пустым

Проблема состояла сразу из нескольких критических ошибок:

1. В `index.html` отсутствовало подключение `js/script.js`. JavaScript вообще не загружался.
2. В `css/style.css` секции `.reveal` имеют `opacity: 0`, а `#hero` также скрыт через `opacity: 0`. Без рабочего JavaScript они не могли появиться.
3. В `js/script.js` была синтаксическая ошибка около строки 147: второй блок Reveal был вставлен внутрь объекта `WeddingApp` между его методами.
4. В одном файле повторно объявлялись `atmosphereCards`, `selectedAtmosphere` и `copyButton`, что после первого исправления привело бы к новой ошибке `Identifier has already been declared`.

## Другие обнаруженные ошибки

- Два разных обработчика Welcome/Atmosphere.
- Два обработчика RSVP.
- Две реализации галереи/lightbox.
- Несовпадающие ID: `closeLightbox` / `lightboxClose`.
- Несовпадающие ID: `copy-address` / `copyAddress`.
- В HTML используется `data-atmosphere="silent"`, а JavaScript проверял `silence`.
- JavaScript ссылался на отсутствующий файл `music/music.mp3`; в архиве есть `music/wedding.mp3`.
- Таймер был настроен на `12.09.2026 15:00`, хотя в приглашении указано `05.09.2026`, сбор гостей — `15:30`.
- Элементы `.stagger` постоянно оставались прозрачными: CSS ожидал класс `.active` непосредственно на `.stagger`, но JavaScript его не добавлял.
- Отсутствовали `icons/divider.svg` и `icons/phone.svg`.
- Одновременно существовали новая система выбора атмосферы и старый плавающий музыкальный плеер.

## Состояние CSS

Синтаксических ошибок в CSS не обнаружено. Однако файл содержит много повторяющихся блоков и конфликтующих селекторов: `#welcome`, `#hero`, `.reveal`, `.gallery-grid`, `#lightbox`, `#startJourney` и другие описаны несколько раз. Это не всегда ломает сайт, но усложняет дальнейшую разработку.

## Производительность

- Размер проекта без `.git` — около 45 МБ.
- `music/nature.mp3` — около 6,1 МБ.
- `music/wedding.mp3` — около 7 МБ.
- Папки `images` и `gallery` содержат одинаковые копии фотографий.
- Некоторые SVG фактически содержат встроенные PNG и весят до нескольких мегабайт.
- В корне находилась дополнительная ZIP-копия примерно на 11 МБ.

Это можно оптимизировать позже без изменения дизайна.

## Что исправлено в восстановительной сборке

- Создан один чистый `js/script.js` без повторных объявлений.
- JavaScript подключён к HTML через `defer`.
- Исправлены Welcome, выбор атмосферы и пути к аудио.
- Исправлена дата обратного отсчёта: `05.09.2026 15:30`, часовой пояс `+03:00`.
- Исправлены Reveal и Stagger-анимации.
- Исправлены Gallery/Lightbox, Escape и закрытие по фону.
- Исправлено копирование адреса с резервным способом.
- Оставлен один обработчик RSVP.
- Удалён устаревший второй музыкальный плеер.
- Добавлены недостающие `phone.svg` и `divider.svg`.
- Улучшена читаемость выбора атмосферы и мобильная компоновка первого экрана.
- Добавлены базовые `aria`-атрибуты и управление с клавиатуры.

## Проверки восстановительной сборки

- `node --check js/script.js` — успешно.
- Повторных `const`, `let`, `class` в JavaScript нет.
- Все `getElementById()` соответствуют элементам в HTML.
- Повторяющихся HTML ID нет.
- Все локальные ресурсы, указанные в HTML, существуют.
- CSS разобран без синтаксических ошибок.

RSVP пока показывает локальное сообщение и не отправляет данные в Telegram. Подключение Telegram-бота нужно выполнять отдельным этапом после утверждения структуры формы.
